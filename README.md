# 30 Days of AI with Streamlit & Snowflake

This repository documents my journey through the **#30DaysOfAI** challenge by Streamlit.

Over 30 days, I’m building hands-on AI-powered applications using:

- **Streamlit** for interactive UIs
- **Snowflake & Snowpark** for data and AI workflows
- **Snowflake Cortex** for LLMs, embeddings, and RAG

## What this repo contains

- Daily mini-projects (Day 1 → Day 30)
- Each folder contains:
  - Streamlit app code
  - Dependencies
  - Clear documentation

## Why this challenge

- Learn real-world AI app development
- Understand enterprise tools like Snowflake
- Build strong, resume-ready projects
